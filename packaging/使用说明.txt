游戏助手 —— 语音 + 看画面 + DeepSeek 答疑

第一次用
  双击 GameAssistant.exe（或桌面「游戏助手」快捷方式）
  会弹出设置窗：填上 DeepSeek 的 API Key → 点「测试连接」→ 点「开始使用」
  Key 在 platform.deepseek.com 申请，按量付费，问一次几分钱

怎么用
  F2          说一句话（说完静音约 0.8 秒自动结束）
  Ctrl+F2     打字提问
  右键小球    对话 / 历史记录… / 设置… / 语音输入 / 朗读回答 / 通话模式 / 开机自启 / 退出
  托盘图标    双击打开对话，右键同一套菜单（不占任务栏按钮）
              被塞进「隐藏的图标」里的话，把它拖到托盘上就常驻了
  拖小球      换位置，退出时记住
  拖气泡边框  改气泡大小，松手即记住
  Esc         关气泡，焦点回游戏

  快捷键可以在「设置 → 快捷键」里改，点进输入框直接按组合键，
  支持 Ctrl / Alt / Shift / Win + 字母 / 数字 / F1~F24。

通话模式
  打开后麦克风常开，喊「小助手，这 BOSS 怎么打」一句话就行。
  唤醒词和「主人，我在」这句应答都能在「设置 → 语音」里改。
  它只在你的本机转文字判断唤醒词，音频不上传；
  游戏声外放容易误触发，建议戴耳机。

对话记录
  每次问答存在 data\history.jsonl，右键「历史记录…」能翻、能清空。

注意
  · 独占全屏的游戏盖不上任何窗口，请把游戏设成「无边框窗口 / 窗口化全屏」
  · 只读截屏，不注入、不 hook、不模拟键鼠
  · config/settings.json 里存着你的 Key，整个文件夹发人前先清空

自检
  GameAssistant.exe --selftest
  结果写在 %TEMP%\gameassistant_selftest.log
